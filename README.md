# Компьютерная графика

Материалы курса сгруппированы по семестрам.

- [4-й семестр](semester-4/) — лабораторные работы № 1–6, ресурсы и настройки проектов.
- [5-й семестр](semester-5/) — общий движок Metal 4, Xcode workspace и Sandbox для новых лабораторных работ.

## Стиль кода

Во всех исходниках используются четыре пробела для отступа и ширина строки 110 символов.
Типы и методы отделяются пустой строкой; связанные свойства остаются в одном блоке.
В крупных файлах разделы обозначаются `// MARK: - ...`, а этапы длинных методов
разделяются пустыми строками. Тела функций и управляющих конструкций записываются
в несколько строк; пустые реализации могут оставаться однострочными.
В SwiftUI каждый модификатор представления размещается на отдельной строке.

Из корня репозитория:

```sh
./scripts/format-code.sh          # Форматирование отслеживаемых исходников обоих семестров
./scripts/format-code.sh --check  # Проверка без изменения файлов
```

Скрипт использует `swift-format` и `clang-format` из Xcode через `xcrun`.
Настройки хранятся в `.swift-format`, `.clang-format` и `.editorconfig`.
Правила преобразования Swift-кода отключены: форматтер отвечает за оформление,
а смысловое разделение на блоки сохраняется при повторном запуске.
