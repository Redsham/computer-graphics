# Компьютерная графика

Материалы курса сгруппированы по семестрам.

- [4-й семестр](semester-4/) — лабораторные работы № 1–6, ресурсы и настройки проектов.
- [5-й семестр](semester-5/) — раздел для новых лабораторных работ.

## Структура

```text
semester-4/
├── .idea/
├── assets/
├── lab-1/
├── lab-2/
├── lab-3/
├── lab-4/
├── lab-5/
└── lab-6/
semester-5/
└── README.md
```

Проекты 4-го семестра открываются из соответствующих каталогов внутри `semester-4/`.
