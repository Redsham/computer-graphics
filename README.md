# Компьютерная графика

Материалы курса сгруппированы по семестрам.

- [4-й семестр](semester-4/) — лабораторные работы № 1–6, ресурсы и настройки проектов.
- [5-й семестр](semester-5/) — общий движок Metal 4, Xcode workspace и Sandbox для новых лабораторных работ.

## Структура

```text
semester-4/
├── .idea/
├── assets/
├── lab-1/
├── lab-2/
├── lab-3/
├── lab-4/
├── lab-5/
└── lab-6/
semester-5/
├── Engine/
├── GraphicsEngine.xcworkspace/
├── Sandbox.xcodeproj/
├── Sandbox/
└── README.md
```

Проекты 4-го семестра открываются из соответствующих каталогов внутри `semester-4/`.

Для запуска движка 5-го семестра откройте `semester-5/GraphicsEngine.xcworkspace` и выберите схему `Sandbox`. Требования и устройство движка описаны в [README 5-го семестра](semester-5/README.md).
